# SDV Vehicle Status history

[Package](../README.md) · [Automotive knowledge](../../README.md)

## Purpose and Scope

Evolution records and superseded SDV Vehicle Status deliverables retained for
provenance, comparison, and audit questions. This area is not the default source
of current schedule or approval status.

## Extension Rules

Place each maintained historical version in a registered version directory.
Never overwrite an archived original; add a new version and keep the current
selection explicit in the package README.
