# WebUI Screenshots

[Documentation](../README.md) · [Structure Governance](../STRUCTURE_GOVERNANCE.md)

## Purpose and Scope

Historical visual-verification evidence for the five-screen EngineeringOS
WebUI. These images were captured with synthetic disconnected data during
implementation; they are not evidence that a live runtime or deployment was
available. The temporary runtime fixture used for those captures has since
been removed from the production browser bundle.

The approved source mockups remain the visual specification. These screenshots
record the implemented state used for comparison at approximately 1536×1024,
plus a narrow responsive check.

- `knowledge.png` — library and Add knowledge drawer
- `ask-eos.png` — grounded query and source evidence
- `engineering.png` — workflow result, Mermaid, and evidence layout
- `models.png` — provider, role, chat, embedding, and pull-plan controls
- `project.png` — health, actions, configuration, Activity, and confirmation
- `responsive-500.png` — narrow Knowledge/drawer stacking at 500×844

## Extension Rules

Use synthetic, non-sensitive inputs only. Replace screenshots when visual
behavior materially changes, record the comparison in
[the implementation log](../WEBUI_IMPLEMENTATION_LOG.md), and do not store
credentials, private documents, or production results here.
