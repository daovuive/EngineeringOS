# knowledge/standards

[Parent directory](../README.md) · [Structure Governance](../../docs/STRUCTURE_GOVERNANCE.md)

## Purpose and Scope

Technical standards knowledge and sources organized by standard. Record version, source, and scope of application. Learning notes are not confirmation of system compliance.

## Subdirectories

- [ASPICE](ASPICE/README.md): Automotive SPICE notes with version, process area, and source information.
- [AUTOSAR](AUTOSAR/README.md): AUTOSAR concepts, documents, and notes.
- [ISO26262](ISO26262/README.md): ISO 26262 notes with version and source information; distinguishes requirements from interpretations and examples.
- [iSAQB](iSAQB/README.md): iSAQB notes and sources, including syllabus version when applicable.

## Extension Rules

Add files within the scope above and link them from this index. New subdirectories must be registered in the manifest, contain their own README.md, and be linked from the parent README. Follow the process and checks in the Structure Governance document.
