## Mục đích và ranh giới

Kho kiến thức kỹ thuật tích lũy. Chọn thư mục theo mục đích tài liệu: học có tiến độ ở architect/, kiến thức kiến trúc dùng chung ở architecture/, theo domain ở automotive/ hoặc standards/, theo project ở projects/. Quyết định của chính EngineeringOS thuộc ADR/.

## Thư mục con

- [architect](architect/README.md): Chương trình học Architect cá nhân hiện có.
- [architecture](architecture/README.md): Phân loại kiến thức kiến trúc dùng chung đã được manifest dự kiến, khác với tiến độ học cá nhân ở architect/.
- [automotive](automotive/README.md): Kiến thức và nghiên cứu domain Automotive, SDV, OTA, telematics.
- [management](management/README.md): Kiến thức requirements, Scrum, stakeholder và quản lý công việc có thể dùng lại.
- [personal](personal/README.md): Kiến thức rút ra từ trải nghiệm cá nhân: lessons learned, architecture notes, checklist và trade-off.
- [projects](projects/README.md): Kiến thức từ các project theo thư mục project có README riêng: context, design, decisions và lessons learned.
- [software-engineering](software-engineering/README.md): Kiến thức software engineering dùng chung: thiết kế code, testing, build và thực hành phát triển.
- [standards](standards/README.md): Kiến thức và nguồn về tiêu chuẩn kỹ thuật, phân theo chuẩn.

## Khi mở rộng

Thêm file đúng ranh giới trên và liên kết từ mục lục này. Thư mục con mới cần được đăng ký trong manifest, có README.md riêng và liên kết từ README cha. Áp dụng quy trình và kiểm tra trong tài liệu quy tắc cấu trúc.
