# ADR-0002

## Title

Use PowerShell 7 as the Cross-Platform Automation Language

---

## Status

Accepted

---

## Context

Engineering OS requires automation scripts for:

- Project bootstrap
- Environment validation
- Dependency installation
- Running services
- Updating local AI models
- Backup and maintenance

The project is expected to run on:

- Windows
- Linux
- macOS

Initially, two approaches were considered:

1. Maintain PowerShell scripts for Windows and Bash scripts for Linux/macOS.
2. Use PowerShell 7 as the single automation language across all supported platforms.

Maintaining two independent script implementations would duplicate logic, increase maintenance cost, and introduce inconsistencies.

---

## Decision

Engineering OS will use **PowerShell 7 (pwsh)** as the primary automation language.

All project commands such as:

- init
- doctor
- setup
- run
- update
- clean

will be implemented as PowerShell scripts.

Bash scripts will only be introduced when a platform-specific capability cannot reasonably be implemented in PowerShell.

---

## Consequences

### Positive

- Single codebase
- Cross-platform
- Lower maintenance cost
- Consistent developer experience
- Easier testing
- Easier onboarding

### Negative

- Linux users must install PowerShell 7
- Some platform-specific shell features may still require Bash

---

## Alternatives Considered

### Option A

PowerShell for Windows

Bash for Linux

Rejected because:

- duplicated code
- duplicated testing
- duplicated documentation

---

### Option B

Python CLI

Rejected because:

- Python runtime would become a mandatory dependency before project initialization.
- PowerShell is sufficient for automation tasks.
