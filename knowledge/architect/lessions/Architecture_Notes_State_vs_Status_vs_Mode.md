# Architecture Notes

## State vs Status vs Mode vs Condition vs Phase vs Lifecycle vs Health vs Ready vs Availability

### State

-   Internal condition that determines behavior.
-   Trạng thái nội tại quyết định hành vi.

### Status

-   Current progress or situation.
-   Tình trạng hoặc tiến độ hiện tại.

### Condition

-   Boolean rule used for decisions.
-   Điều kiện đúng/sai.

### Mode

-   Operating configuration.
-   Chế độ hoạt động.

### Phase

-   Stage within a process.
-   Giai đoạn trong quy trình.

### Lifecycle

-   Complete life journey.
-   Vòng đời của đối tượng.

### Health

-   Operational health.
-   Tình trạng hoạt động bình thường hay không.

### Ready

-   Ready to receive work.
-   Sẵn sàng nhận request.

### Availability

-   Quality Attribute measuring service accessibility.
-   Thuộc tính chất lượng đo mức độ sẵn sàng phục vụ.

## Summary

  Concept        Meaning
  -------------- -------------------------
  State          Internal condition
  Status         Progress
  Condition      Boolean rule
  Mode           Operating configuration
  Phase          Stage
  Lifecycle      Life journey
  Health         Operational health
  Ready          Ready for traffic
  Availability   Quality Attribute
