# Engineering OS

> AI-powered Engineering Operating System running completely on local hardware.

## Vision

Engineering OS is a collection of AI assistants designed to help Software Engineers,
Feature Owners, Technical Consultants and Solution Architects during the complete
software development lifecycle.

Instead of building a single chatbot, Engineering OS provides multiple specialized
assistants sharing the same knowledge, memory, prompts and tools.

## Goals

- 100% Local AI
- Privacy First
- Engineering Focused
- Extensible
- Production Quality

## Initial Modules

- Meeting Assistant
- Requirement Assistant
- Architecture Assistant
- Code Review Assistant
- Interview Coach
- Learning Coach

## Technology

- Ollama
- Python
- Open WebUI
- ChromaDB
- Qwen
