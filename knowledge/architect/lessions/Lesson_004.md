# Lesson 004 — Architecture Constraints

## Status
Completed.

## 1. English
An architecture constraint limits the solution space available to the architect.

## 2. Giải thích bằng tiếng Việt
Requirement nói system cần gì. Constraint nói solution bị giới hạn như thế nào.

## 3. Architect Mindset
Phân biệt rõ:
- Requirement = system need
- Constraint = solution limitation

## 4. Real-world Case Study
Trong Automotive, standards, legacy systems, mandated technologies hoặc platform limitations có thể trở thành constraints.

## 5. iSAQB Mapping
Constraints là input quan trọng khi lựa chọn architecture và đánh giá alternatives.

## 6. Mini Exercise
Phân biệt requirement và constraint trong một OTA system.

## 7. Reflection
Constraint không nhất thiết nói system muốn gì; nó giới hạn những gì Architect được phép làm.

## 8. Summary
Requirement = WHAT the system needs.
Constraint = limitation on possible solutions.

## 9. Flashcards
- Requirement? → System need.
- Constraint? → Solution limitation.

## 10. Keywords
Constraint, Requirement, Solution Space, Limitation.
