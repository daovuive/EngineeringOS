# SDV Vehicle Status metadata

[Package](../README.md) · [Automotive knowledge](../../README.md)

## Purpose and Scope

Integrity hashes, artifact inventories, ingestion selections, workbook
snapshots, and archival validation records for this package. These files record
package provenance; they are not EngineeringOS runtime configuration.

## Extension Rules

Keep metadata consistent with the artifacts it describes. Do not broaden the
default ingestion set without reviewing duplicate and historical-source risks.
