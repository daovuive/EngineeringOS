## Mục đích và ranh giới

Thử nghiệm có phạm vi, giả thuyết, cách chạy và kết quả. Mỗi experiment là thư mục được đăng ký với README riêng. Khi dùng lâu dài, chuyển kết quả sang đúng nguồn chính và cập nhật liên kết; không gọi thử nghiệm là khả năng production.

## Khi mở rộng

Thêm file đúng ranh giới trên và liên kết từ mục lục này. Thư mục con mới cần được đăng ký trong manifest, có README.md riêng và liên kết từ README cha. Áp dụng quy trình và kiểm tra trong tài liệu quy tắc cấu trúc.
