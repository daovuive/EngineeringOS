# agents

## Mục đích và ranh giới

Định nghĩa vai trò và cách điều phối công việc của AI. Agent chọn skill từ registry, dùng nguồn knowledge/career và kiểm tra kết quả. Workflow tái sử dụng thuộc skills/, không sao chép vào agent. Hiện chưa có agent thực thi được triển khai ở đây.

## Khi mở rộng

Thêm file đúng ranh giới trên và liên kết từ mục lục này. Thư mục con mới cần được đăng ký trong manifest, có README.md riêng và liên kết từ README cha. Áp dụng quy trình và kiểm tra trong tài liệu quy tắc cấu trúc.
